# Инструкции для агентов

## Назначение проекта

Разрабатывайте минимальный рабочий сервис прогнозирования пассажиропотока московских трамваев. Backend — FastAPI, ML-контур — Python, поставка — Docker Compose.

## Перед изменениями

1. Прочитайте `README.md` и README из архива датасета.
2. Проверьте фактическую структуру репозитория и наличие `train.csv`.
3. Не предполагайте, что полный датасет уже загружен.
4. Не распаковывайте и не добавляйте многогигабайтные данные в Git.

## Правила работы с данными

- CSV имеют кодировку UTF-8 и разделитель `;`.
- Используйте `tran_date_time` как timestamp; `input_date_time` ненадёжен.
- Считайте посадкой только запись с `validation_result == 1`.
- Извлекайте номер маршрута из `ngpt_route`.
- Не интерпретируйте `place_id` как остановку: это площадка или депо.
- Базовая единица прогноза: `route × date × hour`.
- Период прогноза: `2025-11-01` — `2025-12-31`.
- Итоговый CSV: `route;date;hour;prediction`, 14 640 строк, `prediction >= 0`.
- Для локальной валидации используйте временное разбиение, а не случайное перемешивание.
- Метрика качества — WAPE-score из `README.md`.

## Правила разработки

- Не коммитьте напрямую в `main`: для изменений создавайте отдельные ветки.
- Merge Request создавайте по усмотрению участников.
- Выбирайте самое простое решение, которое можно воспроизвести.
- Не добавляйте зависимости, сервисы и абстракции без текущей необходимости.
- Не дублируйте подготовку признаков между обучением и инференсом.
- Фиксируйте random seed и версии зависимостей.
- Для нетривиальной логики добавляйте один минимальный проверяемый тест.
- Валидируйте входные данные и возвращайте понятные ошибки API.
- Не коммитьте датасеты, модели, секреты и локальные артефакты.
- После появления кода поддерживайте в `README.md` актуальные команды установки, запуска, обучения, тестирования и Docker-сборки.
- Перед сдачей добавьте в `README.md` воспроизводимые показатели RPS, p95, CPU и RAM.

## Границы первого этапа

Пока полного `train.csv` нет, допустимы только анализ схемы, работа с предоставленными агрегатами и подготовка воспроизводимого baseline. Не выдавайте качество на тестовом примере за итоговое качество модели.
